# Plataforma de Terapia da Mão

Plataforma web em desenvolvimento para apoiar fisioterapeutas e pacientes com materiais educativos para a reabilitação da mão e do punho.

## Tecnologias previstas

- **Back-end:** Java, Spring Boot e Maven
- **Front-end:** Ainda Definindo
- **Banco de dados:** PostgreSQL

> Este projeto está em sua versão inicial. As instruções específicas para configurar e executar a aplicação serão adicionadas conforme a estrutura for definida.

## Como baixar o projeto

1. Instale o [Git](https://git-scm.com/downloads), caso ainda não esteja instalado.
2. Abra o terminal (ou o terminal integrado do VS Code).
3. Acesse a pasta onde deseja guardar o projeto.
4. Na página do repositório no GitHub, clique em **Code** e copie a URL HTTPS.
5. Execute o comando abaixo, substituindo a URL de exemplo pela URL copiada:

   ```bash
   git clone https://github.com/USUARIO/REPOSITORIO.git
   ```

6. Entre na pasta criada pelo Git:

   ```bash
   cd REPOSITORIO
   ```

Também é possível baixar os arquivos sem o Git: na página do repositório, clique em **Code → Download ZIP** e extraia o arquivo no computador.

## Como abrir

Abra a pasta do projeto no Visual Studio Code ou na IDE de sua preferência.

A estrutura e os comandos para instalar dependências, configurar o banco de dados e executar o front-end e o back-end serão documentados aqui quando estiverem definidos.
